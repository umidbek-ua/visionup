# VisionUp Product Doctrine

## Vision

VisionUp exists to help low vision users achieve the highest possible level of display freedom and productivity.

The ultimate goal is to reduce the gap between low vision users and healthy users by providing practical tools that improve reading speed, navigation speed, comfort, focus, and independence.

VisionUp should feel like a complete accessibility toolbox where users can quickly access the exact visual environment they need for any task.

---

## Primary Goal

Enable low vision users to work with digital displays as efficiently, comfortably, and independently as possible.

---

## Design Principles

### 1. Speed First

VisionUp is a productivity tool before it is a feature-rich application.

Every action should require the fewest possible steps.

### 2. Minimal Effort

Users should not perform multiple actions when one shortcut or one click can achieve the same result.

### 3. Real-World Usefulness

Features must solve real low vision problems encountered during daily computer usage.

### 4. Universal Display Accessibility

Solutions should work across browsers, editors, terminals, documents, messaging apps, settings windows, and other desktop applications.

### 5. Profiles Are Work Modes

Profiles are not organizational items.

Profiles represent optimized visual environments such as:

* Reading
* Coding
* Browser
* Presentation
* Night

Switching profiles should instantly transform the display experience.

### 6. Simplicity Over Complexity

Whenever two solutions provide similar value, choose the simpler one.

### 7. Low Vision First

Every UI, backend service, shortcut, database structure, and workflow must prioritize low vision accessibility.

---

## Feature Acceptance Rule

Before implementing any feature, ask:

"Will this help a low vision user work faster, easier, or more independently?"

If not, the feature should be postponed or rejected.

---

## MVP Philosophy

The MVP should contain only features that directly improve:

* Reading speed
* Navigation speed
* Visual comfort
* Accessibility
* Productivity
* Independence

Avoid features that increase complexity without providing measurable benefits to low vision users.
