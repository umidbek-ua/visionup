# VisionUp User Stories

## Zoom

As a low vision user,
I want to zoom in and out quickly,
so that I can see content without interrupting my workflow.

---

As a low vision user,
I want smooth zoom transitions,
so that my eyes do not lose focus when magnification changes.

---

## Profiles

As a low vision user,
I want to switch between accessibility profiles,
so that I can instantly adapt VisionUp for reading, coding, or browsing.

---

## Shortcuts

As a low vision user,
I want custom keyboard shortcuts,
so that I can access accessibility features without opening settings.

---

## Focus

As a low vision user,
I want the mouse pointer area highlighted,
so that I can quickly locate where I am working.

---

As a low vision user,
I want keyboard focus indicators,
so that I always know which element is currently selected.

---

## Reading

As a low vision user,
I want a reading mode,
so that text becomes easier to read and causes less eye strain.

---

As a low vision user,
I want text enlargement,
so that I can comfortably read content without changing system settings.

---

## Contrast

As a low vision user,
I want dark backgrounds without affecting images or text colors,
so that applications remain readable and visually correct.

---

## Multi-Display

As a low vision user,
I want a dedicated zoom display on a second monitor,
so that I can view magnified content while keeping my primary display unchanged.

---

As a low vision user,
I want the zoomed display to automatically follow my cursor or focus,
so that I can work faster and with less effort.

---

## Productivity

As a low vision user,
I want accessibility settings to be available in one place,
so that I do not need to configure multiple tools and system settings.

---

As a low vision user,
I want VisionUp to reduce the effort required to use a computer,
so that I can achieve productivity levels closer to fully sighted users.
