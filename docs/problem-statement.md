Problem:
Low vision users need to configure multiple operating system settings and third-party tools to achieve a comfortable viewing experience.

Solution:
VisionUp provides a single application that manages zoom, profiles, shortcuts and accessibility enhancements from one place.

Target:
Low vision desktop users.

MVP:
- Zoom
- Profiles
- Shortcuts

Future:
- OCR
- AI Assistant
- Focus Tracking
- Mouse Enhancements
