# VisionUp

Our goal is not simply to zoom the screen. Our goal is to help low vision users work with displays as efficiently, comfortably, and independently as possible.

VisionUp combines carefully selected accessibility tools such as zooming, display optimization, reading assistance, profiles, shortcuts, and workflow automation into a single experience.

### Mission

Provide low vision users with the highest possible level of display freedom, productivity, and independence.

### Core Principle

Every feature must answer a single question:

"Does this help a low vision user work faster, more comfortably, and more independently?"

If the answer is no, the feature does not belong in VisionUp.
